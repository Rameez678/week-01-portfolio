# My Portfolio

My personal portfolio site, built with HTML, CSS, JavaScript and Bootstrap 5. It covers who I am, the skills I've been building, my projects and how to get in touch.

This was the Week 1 assignment on my Sarah Academy full-stack course: build a responsive portfolio using HTML, CSS and Bootstrap.

## What's on the page

- About me, skills and projects
- A project section you can filter by type
- My experience as a timeline
- A contact form that checks you've filled it in properly before opening your email app
- Works on mobile, tablet and desktop. The navbar collapses into a menu on small screens

## Built with

- HTML and CSS
- Bootstrap 5 (grid, navbar, scrollspy, form validation)
- Bootstrap Icons
- Plain JavaScript for the typing effect, project filter and form

## Running it

There's nothing to install. Open `index.html` in your browser, or use the Live Server extension in VS Code.

## What I learned

This was my first proper go at using Bootstrap's grid. I got much more comfortable with how the breakpoints work. I also learned to change Bootstrap's look with my own CSS instead of fighting against it. One thing that caught me out: large gutters (`g-5`) made the page scroll sideways on phones, so I used smaller gutters on mobile.
